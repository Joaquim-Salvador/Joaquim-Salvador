## Sobre mim

Sou desenvolvedor em início de carreira, de Joinville (SC). Trabalho principalmente com **Java e Spring Boot** no back-end e **Angular** no front-end, e meu objetivo é construir produtos completos, do banco de dados até a interface.

- 🎓 Cursando Engenharia de Software na Univille (2026–2030)
- 📜 Técnico em Desenvolvimento de Software pelo SENAI (2023–2025)
- 🔎 Procurando estágio em desenvolvimento de software
- 🧪 Dois projetos com versão online: um classificador de emails com IA e um gerador de certificados
